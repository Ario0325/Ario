== مرحله 1: تست وبهوک ==
توی کنسول Bash PythonAnywhere این دستور رو اجرا کن:

python3.13 -c "import requests; r = requests.post('https://tjnryhbtgvrfdcs.app.n8n.cloud/webhook/django-auth-event', json={'event':'register','email':'test@test.com','username':'test','code':'123456','reset_link':'','sender_email':'bardiaabdi1393@gmail.com'}, headers={'Content-Type':'application/json','X-Webhook-Secret':'ario-shop-secret-token'}, timeout=15); print(f'Status: {r.status_code}, Response: {r.text}')"

== خروجی احتمالی ==

خروجی 1: Status: 200, Response: {"status":"ok","message":"email sent"}
→ وبهوک کار میکنه. مشکل از جای دیگه‌ست. برو مرحله 3.

خروجی 2: ConnectionError یا Timeout
→ PythonAnywhere نمیتونه به n8n وصل بشه.
→ احتمالاً پلن رایگان بلاک میکنه.
→ راه حل: ارتقا به پلن Hacker یا استفاده از PythonAnywhere Anywhere Tasks.

خروجی 3: 401 یا 403
→ n8n درخواست رو رد کرده.
→ چک کن Workflow فعال باشه.

خروجی 4: ModuleNotFoundError: No module named 'requests'
→ requests نصب نیست.
→ اجرا کن: pip3.13 install requests

== مرحله 2: اگه وبهوک کار کرد ولی ثبت‌نام still خطا میده ==
لاگ‌های Django رو چک کن:

tail -100 /var/log/AryaAbdi1850325.pythonanywhere.com.error.log

== مرحله 3: چک کن n8n ==
1. وارد n8n.cloud بشو
2. Workflow رو باز کن
3. toggle بالای صفحه Active باشه (سبز)
4. روی تب "Executions" کلیک کن
5. ببین آیا webhook دریافت شده
6. اگه دریافت شده ولی خطا داره، روی نود خطا کلیک کن تا جزئیات رو ببینی

== مرحله 4: چک کن SMTP ==
1. توی n8n روی نود "Send Verification Email" کلیک کن
2. بخش Credential باید "Gmail SMTP" باشه
3. اگه "Not set" هست، روی انتخاب کن و "Gmail SMTP" رو بذار
4. همین کار رو برای "Send Password Reset Email" و "Send Order Confirmation Email" هم بکن

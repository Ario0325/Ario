== مشکل ==
DisallowedHost: Invalid HTTP_HOST header: 'aryaabdi1850325.pythonanywhere.com'
یعنی دامنه شما توی ALLOWED_HOSTS نبود.

== علت ==
فایل .env که قبلاً ساختم، ALLOWED_HOSTS=localhost,127.0.0.1 داشت.
این مقدار، مقدار پیش‌فرض settings.py رو override میکرد و دامنه شما حذف میشد.

== راه حل ==
1. ALLOWED_HOSTS از .env حذف شد
2. settings.py طوری تنظیم شد که همیشه دامنه‌های PythonAnywhere رو داشته باشه
   (حتی اگه .env مقدار متفاوتی بده)

cd ~/Ario
git pull origin main

بعد از صفحه Web → Reload بزن.

============================================================
  رفع مشکل loaddata - آریو شاپ
============================================================

== مشکل ==
UNIQUE constraint failed: Accounts_Module_userprofile.user_id
signal پروفایل کاربر هنگام loaddata اجرا میشد و تکراری میساخت.

== راه حل ==
signal اصلاح شد (raw=True رو نادیده میگیره).
حالا این دستورات رو اجرا کن:

cd ~/Ario
git pull origin main
rm -f db.sqlite3
python3.13 manage.py migrate
python3.13 manage.py loaddata db.json

== توضیح ==
1. git pull → کد جدید با signal اصلاح‌شده رو میگیره
2. rm db.sqlite3 → دیتابیس قدیمی رو حذف میکنه
3. migrate → جدول‌های خالی رو میسازه
4. loaddata → داده‌ها رو بدون تداخل میریزه

=== راهنمای رفع مشکل PWA - آریو شاپ ===
=== نسخه جدید - بدون collectstatic ===

=== تغییرات انجام شده ===
1. WhiteNoise حذف شد (نیازی به collectstatic نیست)
2. manifest از طریق Django view سرو میشه با Content-Type درست
3. service worker از فایل source خونده میشه (نه staticfiles)

=== مراحل دیپلوی روی PythonAnywhere ===

مرحله 1: کد رو pull کن
وارد کنسول Bash بشو و اجرا کن:

cd ~/Ario
git pull origin main

مرحله 2: Static File Mapping تنظیم کن (مهم!)
این مرحله خیلی مهمه. بدون اون فایل‌های استاتیک 404 میشن.

1. برو به صفحه "Web" توی پنل PythonAnywhere
2. بخش "Static files" رو پیدا کن
3. روی "Add a new static file mapping" کلیک کن
4. این مقادیر رو وارد کن:
   URL: /static/
   Directory: /home/aryaabdi1850325/Ario/static
5. روی "Add" کلیک کن

مرحله 3: وب‌اپ رو Reload کن
از همون صفحه Web روی دکمه "Reload" بزن.

مرحله 4: تست کن
مرورگر رو باز کن و برو به:
https://aryaabdi1850325.pythonanywhere.com/

=== نحوه تست PWA ===

تست 1: فایل‌های استاتیک
توی مرورگر این آدرس‌ها رو باز کن:
https://aryaabdi1850325.pythonanywhere.com/static/assets/css/style.css
باید کد CSS بیاد (نه 404)

https://aryaabdi1850325.pythonanywhere.com/static/assets/images/icons/site.webmanifest
باید JSON بیاد (نه 404)

تست 2: Manifest
توی مرورگر این آدرس رو باز کن:
https://aryaabdi1850325.pythonanywhere.com/manifest.json
باید JSON بیاد با اسم "آریو شاپ"

تست 3: Service Worker
توی مرورگر این آدرس رو باز کن:
https://aryaabdi1850325.pythonanywhere.com/sw.js
باید کد JavaScript بیاد

تست 4: Chrome DevTools
1. برو به سایت
2. راست‌کلیک → Inspect → تب Application
3. از سمت چپ روی "Manifest" کلیک کن
4. باید اطلاعات زیر رو ببینی:
   - name: فروشگاه آریو شاپ
   - short_name: آریو شاپ
   - start_url: /
   - icons: 3 آیکون
   - screenshots: 2 اسکرین‌شات
5. از سمت چپ روی "Service Workers" کلیک کن
6. باید Status: "activated and is running" باشه

تست 5: نصب PWA
اگه همه چیز درست باشه:
- Chrome دسکتاپ: آیکون نصب (+) توی نوار آدرس ظاهر میشه
- Chrome موبایل: منوی سه‌نقطه → "افزودن به صفحه اصلی"

=== اگه بازم ارور داشتی ===

از Chrome DevTools اسکرین‌شات بگیر و بفرست:
1. تب Application → Manifest
2. تب Application → Service Workers
3. تب Console (ارورهای قرمز)
4. تب Network (فایل‌هایی که 404 هستن)

=== ارورهای رایج و راه حل ===

ارور: "Icon failed to load"
→ یعنی static file mapping تنظیم نشده
→ مرحله 2 رو انجام بده

ارور: "Manifest 'start_url' is not valid"
→ git pull origin main رو اجرا کن

ارور: "molla" (اسم قدیمی)
→ git pull origin main رو اجرا کن

ارور: Service Worker ثبت نمیشه
→ مطمئن شو /sw.js 200 برمیگردونه
→ static file mapping رو چک کن

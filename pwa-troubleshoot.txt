== نتیجه تست ==
وبهوک n8n از اینجا تست شد و کار میکنه:
Status: 200 - Response: {"status":"ok","message":"email sent"}
یعنی URL درسته و n8n فعاله.

== مشکل احتمالی ==
PythonAnywhere نمیتونه به n8n.cloud درخواست بفرسته.
یا کد قدیمی هنوز روی سروره.

== مراحل عیب‌یابی ==

مرحله 1: چک کن کد آپدیت شده
توی کنسول Bash PythonAnywhere اجرا کن:

cd ~/Ario
git pull origin main
cat Ario_Shop/settings.py | grep tjnryhbtgvrfdcs

خروجی باید این باشه:
N8N_WEBHOOK_URL = os.environ.get('N8N_WEBHOOK_URL', 'https://tjnryhbtgvrfdcs.app.n8n.cloud/webhook/django-auth-event')

مرحله 2: تست وبهوک از PythonAnywhere
توی کنسول Bash اجرا کن:

python3.13 -c "
import requests
url = 'https://tjnryhbtgvrfdcs.app.n8n.cloud/webhook/django-auth-event'
payload = {'event':'register','email':'test@test.com','username':'test','code':'123456','reset_link':'','sender_email':'bardiaabdi1393@gmail.com'}
headers = {'Content-Type':'application/json','X-Webhook-Secret':'ario-shop-secret-token'}
try:
    r = requests.post(url, json=payload, headers=headers, timeout=15)
    print(f'Status: {r.status_code}')
    print(f'Response: {r.text}')
except Exception as e:
    print(f'Error: {type(e).__name__}: {e}')
"

خروجی احتمالی:
- Status: 200 → وبهوک کار میکنه، مشکل جای دیگه‌ست
- ConnectionError → PythonAnywhere نمیتونه به n8n وصل بشه
- Timeout → n8n کنده یا بلاک شده
- 403 → n8n درخواست رو رد کرده

مرحله 3: چک کن requests نصب باشه
pip3.13 list | grep requests

مرحله 4: چک کن .env وبهوک رو override نکنه
cat ~/Ario/.env | grep N8N

اگه URL قدیمی (localhost) داری، حذفش کن:
nano ~/Ario/.env
خط N8N_WEBHOOK_URL رو حذف کن (یا URL درست رو بذار)

مرحله 5: بعد از هر تغییر
صفحه Web → Reload بزن

مرحله 6: چک کن n8n فعاله
1. وارد n8n.cloud بشو
2. Workflow رو باز کن
3. toggle بالای صفحه Active باشه
4. روی تب "Executions" کلیک کن
5. ببین آیا webhook دریافت شده

مرحله 7: چک کن SMTP تنظیمه
1. توی n8n روی نود "Send Verification Email" کلیک کن
2. Credential روی "Gmail SMTP" باشه
3. نه "Not set" و نه خالی

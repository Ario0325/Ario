=========================================
بخش ۳: تست از داخل PythonAnywhere (مهم‌ترین بخش)
=========================================

این تست‌ها باید روی سرور PythonAnywhere انجام شود.
وارد PythonAnywhere شوید و به تب Consoles بروید.

1. تست اتصال به Worker:
   python3 -c "import requests; r = requests.get('https://quiet-field-a090.mimoomim456.workers.dev/'); print(r.status_code, r.text)"

   اگر خطا گرفت یعنی PythonAnywhere نمی‌تواند به Worker وصل شود.

2. تست ارسال webhook:
   python3 -c "
   import requests
   r = requests.post(
       'https://quiet-field-a090.mimoomim456.workers.dev/webhook/django-auth-event',
       json={
           'event': 'register',
           'email': 'test@test.com',
           'username': 'test',
           'code': '123456',
           'secret_token': 'ario-shop-secret-token',
           'sender_email': 'bardiaabdi1393@gmail.com'
       },
       headers={'Content-Type': 'application/json'},
       timeout=15
   )
   print(r.status_code, r.text)
   "

   اگر 200 برگشت یعنی همه چیز درست است.
   اگر خطا گرفت، پیام خطا را ببینید.

3. تست اتصال مستقیم به n8n (بدون Worker):
   python3 -c "import requests; r = requests.get('https://tjnryhbtgvrfdcs.app.n8n.cloud/'); print(r.status_code)"

   اگر این خطا بدهد ولی Worker کار کند یعنی proxy درست عمل می‌کند.

4. بررسی لاگ‌های PythonAnywhere:
   - به تب Web بروید
   - روی لینک "Error log" کلیک کنید
   - آخرین خطاها را ببینید
   - دنبال "n8n" یا "ConnectionError" یا "Timeout" بگردید

5. بررسی فایل‌های آپلود شده:
   python3 -c "
   import sys
   sys.path.insert(0, '/home/arya0325/Ario')
   from Ario_Shop.settings import N8N_WEBHOOK_URL, N8N_WEBHOOK_SECRET, N8N_ORDER_WEBHOOK_URL
   print('AUTH URL:', N8N_WEBHOOK_URL)
   print('ORDER URL:', N8N_ORDER_WEBHOOK_URL)
   print('SECRET:', N8N_WEBHOOK_SECRET)
   "

   آیا آدرس‌ها به Worker اشاره می‌کنند یا مستقیم به n8n؟


=========================================
بخش ۴: رایج‌ترین مشکلات و راه‌حل‌ها
=========================================

مشکل ۱: آدرس‌ها هنوز به n8n مستقیم اشاره می‌کنند
-----------------------------------------
علت: git pull انجام نشده یا وب‌اپ ریلود نشده
راه‌حل:
  cd ~/Ario
  git pull origin main
  سپس به تب Web بروید و Reload بزنید

مشکل ۲: PythonAnywhere نمی‌تواند به Worker وصل شود
-----------------------------------------
علت: محدودیت network در پلن رایگان
راه‌حل: این باید کار کند چون Worker روی HTTPS است
اگر کار نکرد، تست کنید:
  python3 -c "import requests; r = requests.get('https://httpbin.org/get'); print(r.status_code)"
اگر این هم خطا بدهد یعنی کلاً HTTP خروجی بلاک است.

مشکل ۳: Worker خطا برمی‌گرداند (502)
-----------------------------------------
علت: n8n خواب است (free tier بعد از بی‌فعالیتی sleep می‌کند)
راه‌حل: اول n8n را باز کنید تا بیدار شود، سپس دوباره تست کنید

مشکل ۴: n8n خطای 401 برمی‌گرداند
-----------------------------------------
علت: secret_token اشتباه است
راه‌حل: مطمئن شوید مقدار توکن در settings.py و n8n یکسان است

مشکل ۵: ایمیل نمی‌آید ولی webhook موفق است
-----------------------------------------
علت: مشکل از SMTP credential در n8n
راه‌حل:
  1. در n8n به Executions بروید
  2. آخرین اجرا را باز کنید
  3. آیا نود ایمیل خطا دارد؟
  4. SMTP credential را دوباره تست کنید

مشکل ۶: Timeout از طرف Django
-----------------------------------------
علت: Worker یا n8n خیلی کند پاسخ می‌دهد
راه‌حل: timeout در services.py روی 10 ثانیه تنظیم شده
اگر n8n sleep باشد اولین درخواست ممکن است 30 ثانیه طول بکشد
